# Legal and governance framework

This directory tracks the legal, governance, and trust documents that support AnnLite’s public-interest operating model.

- Main security policy: [SECURITY.md](../../SECURITY.md)
- Governance and migration notes: [docs/governance/MIGRATION.md](../governance/MIGRATION.md)
- Project contribution standards: [CONTRIBUTING.md](../../CONTRIBUTING.md)
- Project terms and legal framing: [apps/web/src/i18n.ts](../../apps/web/src/i18n.ts)

## Core principles

- Do not claim live payment processing before provider verification is complete.
- Do not collect or store card data in browser-only flows.
- Keep all externally hosted donation redirects explicit and clearly labeled.
- Use public documentation to explain provider boundaries, governance, and security assumptions.

## Legal-readiness checklist

- Terms and privacy references are reviewed and linked
- Security vulnerability reporting is private and documented
- Real provider activation requires compliance review, provider verification, and operational approval
- All donor-facing language must be truthful and not misleading
